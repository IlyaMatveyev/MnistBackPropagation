# MnistBackPropagation
Программа, выполняющая обучение нейронной сети для определения рукописных цифр из набора данных MNIST. Используемый метод: Обратное распространение ошибки.
В данном репозитории находятся 2 программы и полный датасет mnist. Первая программа для обучения новой модели нейронной сети (lab1.py). Вторая для использования обученной модели(lab1_useModel.py), в которую можно передать одно изображение и получить предикт модели по полученному изображению. 
# Инструкция по развёртыванию
1. Необходимо клонировать git репозиторий на свой компьютер командой: git clone https://github.com/IlyaMatveyev/MnistBackPropagation
2. Зайти в клонированный репозиторий через командную строку. Команда: cd <путь>\MnistBackPropagation

# Инструкция по обучению модели
1. Находясь в командной строке, в репозитории MnistBackPropagation запуск скрипта обучения выполняется следующей командой:
   <code>python lab1.py --train_dir "<путь до треннировочных данных>" --test_dir "<путь до тестовых данных>" --epochs 20 --lr 0.1 --batch_size 64 --hidden 128<code>
3. При передаче корректных параметров, начнётся процесс обучения.
4. После обучения в дериктории outputs появится готовая модель(mnist_model.pkl) и график истории обучения(training_history.png).

Доступные параметры скрипта обучения: 
1. --train_dir расположение треннировочных данных (следует использовать MnistBackPropagation/mnist/train) (обязательный параметр);
2. --test_dir расположение тестовых данных (следует использовать MnistBackPropagation/mnist/test) (обязательный параметр);
3. --epochs кол-во эпох обучения (по умолчанию = 10);
4. --lr скорость обучения (по умолчанию = 0.1);
5. --batch_size размер батча (по умолчанию = 64);
6. --hidden кол-во нейронов скрытого слоя (по умолчанию = 128);
7. --out_dir директория, в которую будет помещена модель и график истоии обучения (по умолчанию = 'outputs').
