# MnistBackPropagation
Программа, выполняющая обучение нейронной сети для определения рукописных цифр из набора данных MNIST. Используемый метод: Обратное распространение ошибки.
В данном репозитории находятся 2 программы и полный датасет mnist. Первая программа для обучения новой модели нейронной сети (lab1.py). Вторая для использования обученной модели(lab1_useModel.py), в которую можно передать одно изображение и получить предикт модели по полученному изображению. 
# Инструкция по развёртыванию
- Необходимо клонировать git репозиторий на свой компьютер командой: git clone https://github.com/IlyaMatveyev/MnistBackPropagation
- Зайти в клонированный репозиторий через командную строку. Команда: cd <путь>\MnistBackPropagation
# Перед использованием скриптов, необходимо установить используемые библиотеки:
<code>pip install numpy opencv-python matplotlib<code>
# Инструкция по обучению модели
- Находясь в командной строке, в репозитории MnistBackPropagation запуск скрипта обучения выполняется следующей командой: <code>python lab1.py --train_dir "<полный путь до треннировочных данных>" --test_dir "<полный путь до тестовых данных>" --epochs 20 --lr 0.1 --batch_size 64 --hidden 128<code>
- При передаче корректных параметров, начнётся процесс обучения.
- После обучения в дериктории outputs появится готовая модель(mnist_model.pkl) и график истории обучения(training_history.png).
# Доступные параметры скрипта обучения: 
- --train_dir расположение треннировочных данных (следует использовать MnistBackPropagation/mnist/train) (обязательный параметр);
- --test_dir расположение тестовых данных (следует использовать MnistBackPropagation/mnist/test) (обязательный параметр);
- --epochs кол-во эпох обучения (по умолчанию = 10);
- --lr скорость обучения (по умолчанию = 0.1);
- --batch_size размер батча (по умолчанию = 64);
- --hidden кол-во нейронов скрытого слоя (по умолчанию = 128);
- --out_dir директория, в которую будет помещена модель и график истоии обучения (по умолчанию = 'outputs').
# Инструкция по использованию обученной модели:
- Находясь в командной строке, в репозитории MnistBackPropagation запуск скрипта получения предикта моделью выполняется следующей командой: python lab1_useModel.py --model_path "<полный путь к моделе>" --image_path "<полный путь к анализируемому изображению>"
- После работы скрипта на консоль будет выведено предположение используемой модели.
# Доступные параметры скрипта использования модели:
- --model_path расположение используемой модели (обязательный параметр);
- --image_path расположение анализируемого изображения (обязательный параметр);
